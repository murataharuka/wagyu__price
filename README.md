# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
ローカルリポジトリ：自分のパソコン内にある、ファイルや履歴を保存する場所のこと。
リモートリポジトリ：GitHubなど、ネット上にあるファイルや履歴を保存・共有する場所のこと。

## プッシュとマージの違いは何でしょうか？
プッシュ：自分のパソコン（ローカル）の変更履歴を、ネット上（リモート）にアップロードすること。
マージ：枝分かれした別のブランチ（作業内容）を、1つのブランチ（masterなど）に合流させること。

## コミットとプッシュの違い
コミット：自分のパソコン内（ローカル）に、ファイルの変更内容を「記録・保存」すること。
プッシュ：その記録した内容を、ネット上（リモート）のGitHubへ「送信」すること。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
他の人が見ても「何の変更をしたか」が一目でわかるように、具体的かつ簡潔な言葉で書くのが最適です。
例：「ボタンを青に変更」「トップページのデザイン修正」など


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
ローカルでマージ：自分のパソコン内だけで完結する合流作業。
プルリクエストでマージ：GitHub上で「この変更を合流させていいですか？」とチームに確認してもらい、レビューをもらってから合流させる作業。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
競合（バッティング）しているファイルを開き、Gitが自動挿入した記号（<<<<<<< や ======= など）を目印に、どちらのコードを残すか手動で修正して保存します。その後、再度ステージング（add）してコミットします。
